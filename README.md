# Homelab-Network
Over the past year, I’ve been building and expanding my cybersecurity home lab to strengthen my hands-on experience in networking, system administration, virtualization, and security engineering.

What started as a simple setup quickly turned into a full enterprise-style lab environment focused on network segmentation, secure remote access, firewall policy enforcement, VLAN design, virtualization, and infrastructure monitoring.

My current lab includes:
• Cisco Systems routing and switching
• Fortinet FortiGate firewall management
• Proxmox VE virtualization for isolated Windows/Linux testing environments
• Docker-hosted services like Jellyfin, Nextcloud, and Pi-hole
• VPN-only remote access using Tailscale and WireGuard for reduced public exposure
• Monitoring and visibility through secure infrastructure design and segmentation

This lab has become one of the most valuable parts of my growth in cybersecurity because it allows me to move beyond theory and work through real troubleshooting, security decisions, and architecture design challenges.
